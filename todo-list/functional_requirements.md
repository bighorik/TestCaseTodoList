# Функциональные требования к приложению TodoList

## 1. Общее описание
TodoList - это веб-приложение для управления задачами с возможностью добавления, редактирования, удаления и отслеживания статуса выполнения задач.

## 2. Основные функции

### 2.1 Добавление задач
- Пользователь может добавить новую задачу через модальное окно
- Форма добавления содержит следующие поля:
  - Название (обязательное, минимум 5 символов)
  - Крайний срок выполнения (обязательное, не может быть раньше текущей даты)
  - Срочность (3 уровня: Не срочно, Срочно, Очень срочно)
  - Описание (необязательное)
  - Цвет подсветки (выбор цвета)

### 2.2 Управление задачами
- Просмотр списка задач
- Отметка задач как выполненных/не выполненных
- Удаление задач с подтверждением
- Фильтрация задач по статусу (все, не выполненные, выполненные)

## 3. Требования к валидации данных

### 3.1 Обязательные поля
- Название задачи
- Крайний срок выполнения

### 3.2 Правила валидации
- Название задачи должно содержать не менее 5 символов
- Дата не может быть раньше текущей даты

## 4. Требования к отображению

### 4.1 Список задач
- Задачи отображаются с цветовой индикацией срочности
- Каждая задача отображает:
  - Название
  - Крайний срок выполнения
  - Срочность
  - Описание
- Визуальное различие между выполненными и не выполненными задачами

### 4.2 Вкладки фильтрации
- Вкладка "Все задачи" - отображает все задачи
- Вкладка "Не выполненные" - отображает только невыполненные задачи
- Вкладка "Выполненные" - отображает только выполненные задачи

## 5. Требования к взаимодействию

### 5.1 Добавление задачи
- Кнопка "Добавить задачу" в заголовке приложения
- Модальное окно с формой добавления
- Валидация данных перед сохранением
- Отображение ошибок валидации под соответствующими полями

### 5.2 Управление задачами
- Кнопка "Выполнить" для отметки задачи как выполненной
- Кнопка "Отменить выполнение" для возврата задачи в невыполненные
- Кнопка "Удалить" для удаления задачи
- Диалог подтверждения при удалении задачи

### 5.3 Навигация
- Переключение между вкладками фильтрации
- Адаптивная верстка для мобильных устройств

## 6. Технические требования

### 6.1 Требования к реализации
- Использование React с TypeScript
- Адаптивный дизайн с использованием CSS-переменных
- Совместимость с современными браузерами

### 6.2 Дизайн
- Чистый и современный интерфейс
- Цветовая индикация срочности задач
- Анимации при наведении и взаимодействии
- Соблюдение принципов UX/UI

## 7. Дополнительные возможности

### 7.1 Удобство использования
- Автоматическая генерация случайного цвета при добавлении задачи
- Увеличенная высота инпута выбора цвета для лучшей видимости
- Ширина контента 100% с максимальной шириной 800px
